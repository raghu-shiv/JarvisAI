# .codex

This folder contains project-local guidance for Codex sessions working on JarvisAI.

It is intentionally lightweight:

- `config.toml` records the operating constraints for Codex.
- `project-rules.md` explains the same rules in human-readable form.
- No secrets belong here.
- No generated machine state belongs here.
- No local credentials, tokens, API keys, or Docker state should be added here.

The authoritative project-level agent instructions are also summarized in the root `AGENTS.md`.
